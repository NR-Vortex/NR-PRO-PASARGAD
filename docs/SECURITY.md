# راهنمای امنیت NRX VPN

**وضعیت: Development Preview — استفاده عملیاتی هنوز تأیید نشده است.**

## مدیریت اطلاعات محرمانه

فایل `.env`، Token ربات تلگرام، رمز دیتابیس و Redis، کلید رمزنگاری پنل، داده کاربران و اطلاعات حساب پنل نباید در Git، گزارش خطا یا Issue عمومی منتشر شوند. `.env.example` تنها جای نگهداری نام متغیرها و مقدارهای غیرحساس نمونه است.

چنانچه یک رمز یا توکن در تاریخچه عمومی Git قرار گرفته، حذف آن از شاخه بعدی کافی نیست. اعتبارنامه را باطل یا تعویض کنید و تاریخچه را جداگانه بررسی کنید.

## حفاظت از عملیات نوشتن

`NR_PANEL_STATUS_WRITE_ENABLED=0` پیش‌فرض ایمنِ تنظیمات توسعه است. فعال‌سازی نوشتن مستلزم مجوز، تأیید شرایط محیط، بررسی سرویس مربوطه و آزمون قبلی است. نباید برای امتحان‌کردن سریع امکانات، این پرچم یا تأییدیه مربوطه را فعال کرد.

## سرویس‌های خارجی

ارتباط با Telegram، 3X-UI، Marzban، PostgreSQL و Redis را پیش از آزمون روی محیط واقعی با حساب و داده آزمایشی ارزیابی کنید. Redis نباید بدون نیاز روی اینترنت Publish شود. در Production گواهی TLS، محدودیت دسترسی، شبکه خصوصی و پیکربندی امن سرویس‌ها ضروری است.

## گزارش مشکل امنیتی

از انتشار جزئیات بهره‌برداری یا Secret در Issue عمومی پرهیز کنید. تا زمان راه‌اندازی کانال محرمانه رسمی، ابتدا با مالک مخزن از مسیر خصوصی تماس بگیرید و فقط خلاصه بدون داده حساس را عمومی کنید.

## انتشار نسخه

قبل از برچسب Production باید حداقل ممیزی Secrets و Git History، تست‌های یکپارچه، راه‌اندازی یک VPS تمیز، پشتیبان‌گیری/بازیابی و Rollback با موفقیت بررسی شوند.
